برای کاربران حرفه‌ای

این بخش برای کسانی است که برنامه‌ی اندروید/ویندوز MolidoVPN یا اپ Hiddify روی آیفون برایشان کافی نیست و می‌خواهند از برنامه‌های دیگر، DNS مخصوص بازی یا راه‌های جایگزین استفاده کنند. اگر همه‌چیز خوب کار می‌کند، نیازی به باز کردن این بخش نیست.

لینک‌های اشتراک — برای اتصال دستی در Hiddify، Streisand، Karing یا v2rayNG

فقط اگر می‌خواهید خودتان سرور را در یکی از این برنامه‌ها اضافه کنید به این لینک‌ها نیاز دارید؛ برنامه‌ی اندروید و ویندوز MolidoVPN نیازی به آن‌ها ندارد. هر لینک ۵۰ تا ۱۰۰ سرور متفاوت دارد؛ ۲ یا ۳ تا اضافه کنید.

اتصال آیفون از طریق هات‌اسپات گوشی اندروید (بدون نصب هیچ اپی)

اگر گوشی اندروید کنارتان است و MolidoVPN رویش وصل است، می‌توانید بدون نصب چیزی روی آیفون، اینترنتش را از طریق هات‌اسپات به اشتراک بگذارید.

  1. روی اندروید: MolidoVPN را وصل کنید ← تنظیمات ← «اشتراک با آیفون و لپ‌تاپ» را روشن کنید.
  2. هات‌اسپات اندروید را روشن کنید و آیفون را به آن وصل کنید.
  3. آیفون: Settings ← Wi-Fi ← ⓘ ← Configure Proxy ← Manual.
  4. Server = آی‌پی نوشته‌شده روی کارت اندروید، Port = 8080 ← Save.

لپ‌تاپ ویندوز هم به همین شکل: Settings ← Network ← Proxy ← Manual proxy ← همان IP و پورت 8080.

ابزارهای تکمیلی — پینگ بازی و راه‌های جایگزین وقتی همه‌چیز بسته است

این‌ها برای موقعیت‌های خاص است، نه استفاده‌ی روزمره.

🎮 DNS گیمینگ — برای کم‌کردن پینگ و باز کردن بازی‌های تحریم‌شده

مخصوص کسانی که بازی آنلاین انجام می‌دهند. این DNSهای ایرانی پینگ را کم می‌کنند و بعضی بازی‌های تحریم‌شده را باز می‌کنند؛ فقط داخل اینترنت ایران کار می‌کنند.

  • رادار گیم: 10.202.10.10 و 10.202.10.11
  • الکترو: 78.157.42.100 و 78.157.42.101
  • شکن: 178.22.122.100 و 185.51.200.2
  • 403: 10.202.10.202 و 10.202.10.102

همراه با VPN روشن، در این برنامه‌ها:

برنامهتنظیم
MolidoVPN اندروید/ویندوزتنظیمات ← DNS ← DNS گیمینگ (اندروید ۱۳ به بالا کامل)
Hiddify (آیفون/اندروید/ویندوز)Settings ← DNS ← Direct DNS = 10.202.10.10 و Region = Iran
Karing آیفونSettings ← DNS ← Direct همان آدرس + قانون ایران
v2rayNG اندرویدDomestic DNS = 10.202.10.10 و مسیریابی Bypass Iran

آیفون بدون VPN (فقط Wi-Fi): Settings ← Wi-Fi ← ⓘ ← Configure DNS ← Manual ← دو آدرس بالا ← Save. برای برگشت «Automatic».

نام منوها در نسخه‌های مختلف ممکن است کمی فرق کند. وقتی VPN روشن است، DNS دستی آیفون استفاده نمی‌شود.

برنامه‌های پشتیبان — وقتی MolidoVPN هم فیلتر شد (Psiphon، 1.1.1.1، Orbot)

فقط در شرایط سخت فیلترینگ لازم می‌شود، به‌عنوان آخرین راه‌حل.

  • Psiphon — وقتی همه‌چیز بسته است؛ خودش راه پیدا می‌کند.
  • 1.1.1.1 — وب‌گردی سریع؛ ولی کشور خروجی ایران است.
  • Orbot (Tor) — آخرین راه؛ کند ولی مقاوم (Snowflake را روشن کنید).
