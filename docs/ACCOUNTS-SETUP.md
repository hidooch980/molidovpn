# راه‌اندازی حساب کاربری و پنل مدیریت (یک بار، حدود ۱۰ دقیقه)

## ۱. ساخت پروژه‌ی سوپابیس
1. به https://supabase.com بروید و با گیت‌هاب یا ایمیل وارد شوید.
2. **New project** → یک نام (مثلاً `mobin-vpn`) و یک رمز دیتابیس → منطقه‌ی نزدیک (Frankfurt) → **Create**.

## ۲. ساخت جدول‌ها
1. در پروژه: **SQL Editor** → **New query**.
2. کل محتوای فایل `supabase/schema.sql` را بچسبانید و **Run** بزنید.

## ۳. تنظیم ورود
**Authentication → Sign In / Providers → Email**:
- اگر نمی‌خواهید کاربران ایمیل تأیید بگیرند، **Confirm email** را خاموش کنید (ساده‌تر برای خانواده).

## ۴. فرستادن کلیدها برای من
**Project Settings → API**:
- **Project URL** (مثل `https://abcd.supabase.co`)
- **anon public** key

این دو را بفرستید. (کلید anon عمومی است و با قوانین امنیتی دیتابیس محافظت می‌شود؛ کلید `service_role` را هرگز نفرستید.)

## ۵. مدیر شدن
بعد از اینکه نسخه‌ی جدید برنامه ساخته شد، یک بار با ایمیل خودتان در برنامه ثبت‌نام کنید. سپس در **SQL Editor**:

```sql
insert into public.admins (user_id) select id from auth.users where email = 'ایمیل-شما@gmail.com';
```

## پنل
آدرس پنل: https://hidooch980.github.io/molidovpn/

- لیست کاربران: نام، ایمیل، مصرف کل، دانلود/آپلود، دستگاه، آخرین فعالیت
- **قطع کاربر / وصل کاربر**: کاربر قطع‌شده حداکثر تا ۱ دقیقه از VPN جدا می‌شود و دیگر نمی‌تواند وصل شود
- **آزاد کردن دستگاه**: هر حساب روی یک دستگاه کار می‌کند؛ برای عوض کردن گوشی، دستگاه را آزاد کنید
